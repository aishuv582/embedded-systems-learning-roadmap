8051 Microcontroller

The 8051 is an 8-bit microcontroller originally developed by Intel. It is widely used for learning embedded systems and understanding microcontroller architecture.

Basic features of the classic 8051:

8-bit CPU
4 KB program (ROM)
128 bytes RAM
32 I/O pins → 4 ports (P0–P3)
2 timers/counters → Timer 0 and Timer 1
5 interrupt sources
Full-duplex UART for serial communication
16-bit program counter
16-bit DPTR (Data Pointer)
