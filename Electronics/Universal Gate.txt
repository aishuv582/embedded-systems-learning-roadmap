A universal logic gate is a logic gate that can be used to implement any Boolean function without needing any other type of gate.

The two universal logic gates are:

NAND (NOT-AND) gate
NOR (NOT-OR) gate
Why are they called universal?

Using only NAND gates or only NOR gates, you can construct all the basic logic gates:

Logic Gate	Using NAND	Using NOR
NOT	✓	✓
AND	✓	✓
OR	✓	✓
XOR	✓	✓
XNOR	✓	✓

Therefore, any digital circuit can be built using only NAND gates or only NOR gates.

Key points to remember
Universal gates: NAND and NOR
NAND = NOT of AND
NOR = NOT of OR
Any Boolean expression or digital circuit can be implemented using only NAND gates or only NOR gates.
