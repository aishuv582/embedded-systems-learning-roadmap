A microprocessor mainly contains the CPU.

A microcontroller contains several components inside one chip:

              8051 MICROCONTROLLER
                     │
       ┌─────────────┼─────────────┐
       │             │             │
      CPU          Memory        I/O Ports
       │             │             │
   ALU + CU       RAM + ROM      P0 P1 P2 P3
       │
   Registers
       │
 ┌─────┴─────┐
 │           │
Timers     Serial Port
 │           │
T0, T1      UART
 │
Interrupts

So, a microcontroller is essentially a small computer on a single chip.

🔹 Basic 8051 Architecture

A classic 8051 has:

Feature	8051
CPU	8-bit
ROM/Program Memory	4 KB
RAM	128 bytes
I/O Ports	4
I/O Pins	32
Timers/Counters	2
Serial Port	1
Interrupt sources	5
Addressable memory	64 KB program + 64 KB external data
Oscillator	Typically 11.0592 MHz or 12 MHz in traditional designs

These are the specifications of the classic 8051, not every modern 8051-compatible derivative.

🔹 1. CPU

The CPU (Central Processing Unit) is the brain of the 8051.

It performs:

Arithmetic operations
Logical operations
Data movement
Program execution
Decision making

The CPU contains important parts such as:

ALU – Arithmetic Logic Unit

Performs operations like:

Addition
Subtraction
AND
OR
XOR
Comparison
Increment
Decrement
Control Unit

Controls the sequence in which instructions are executed.

🔹 2. Registers

Registers are small, fast storage locations inside the CPU.

Important 8051 registers include:

Accumulator — A

The A register is one of the most important registers.

Example:

MOV A,#25H
ADD A,#10H

Here, 25H is loaded into A and then 10H is added.

B Register

The B register is mainly used during:

MUL AB
DIV AB

It can also be used as a general-purpose register.

Program Counter — PC

The Program Counter stores the address of the next instruction to be executed.

Example:

1000H → Instruction
1001H → Instruction
1002H → Instruction

PC keeps track of where the CPU should fetch the next instruction.

Stack Pointer — SP

The Stack Pointer points to the current top of the stack.

It is important during:

Subroutines
Function calls
Interrupts
PUSH/POP operations
Program Status Word — PSW

PSW contains important status/control flags.

Some important flags are:

CY → Carry
AC → Auxiliary Carry
OV → Overflow
P  → Parity
🔹 3. Memory

The classic 8051 has two main types of internal memory:

Program Memory

Used to store the program/instructions.

Classic 8051:

4 KB ROM
Data Memory

Used for temporary data.

Classic 8051:

128 bytes RAM

The 8051 also supports external memory expansion.

🔹 4. I/O Ports

The 8051 has four 8-bit ports:

Port 0 → P0.0 – P0.7
Port 1 → P1.0 – P1.7
Port 2 → P2.0 – P2.7
Port 3 → P3.0 – P3.7

Therefore:

4 × 8 = 32 I/O pins

These pins allow the 8051 to communicate with external devices.

For example:

8051 → LED
8051 → LCD
8051 → Keypad
8051 → Sensor
8051 → Motor driver
Important point

Port 3 has alternate functions.

For example:

P3.0 → RXD
P3.1 → TXD
P3.2 → INT0
P3.3 → INT1
P3.4 → T0
P3.5 → T1
P3.6 → WR
P3.7 → RD

This is particularly important for embedded interviews.

🔹 5. Timers/Counters

The classic 8051 contains:

Timer 0
Timer 1

They can operate as timers or counters.

Timer

Used to generate delays or measure time.

8051 → Timer → Delay
Counter

Used to count external events.

External pulses → Counter → Count

This is one of the important 8051 topics for embedded programming.

🔹 6. Serial Communication

The 8051 has a built-in serial port, commonly used for UART communication.

Two important signals are:

TXD → Transmit Data
RXD → Receive Data

Example:

8051 TXD ─────────→ PC RX
8051 RXD ←───────── PC TX

This allows the 8051 to communicate with another device.

🔹 7. Interrupts

An interrupt allows an external or internal event to temporarily stop the normal program execution.

For example:

Main Program
     ↓
     ↓
Interrupt occurs
     ↓
Interrupt Service Routine
     ↓
Return to main program

Classic 8051 has 5 interrupt sources:

External Interrupt 0
Timer 0 Interrupt
External Interrupt 1
Timer 1 Interrupt
Serial Interrupt
🔹 8. Oscillator / Clock

The microcontroller needs a clock to execute instructions.

Traditionally, an external crystal oscillator is connected to:

XTAL1
XTAL2

A commonly used crystal is:

11.0592 MHz

Why is 11.0592 MHz popular?

Because it makes common UART baud-rate generation convenient.

🔹 How 8051 Works

Suppose we want to turn ON an LED.

The basic process is:

Program stored in memory
          ↓
CPU fetches instruction
          ↓
CPU decodes instruction
          ↓
CPU executes instruction
          ↓
Output sent through I/O port
          ↓
LED turns ON

For example:

MOV P1,#01H

This sends:

P1 = 00000001

So one particular Port 1 pin can be driven according to the hardware connection.
