MUX vs DEMUX

MUX (Multiplexer) and DEMUX (Demultiplexer) are digital circuits used to select and route data.

1. Multiplexer (MUX)

A MUX selects one input from multiple inputs and sends it to one output.

👉 Many → One

Example: 4:1 MUX

 I0 ──┐
 I1 ──┤
 I2 ──┤──► MUX ───► Y
 I3 ──┘
       ▲
      S0 S1
   Select lines

There are:

4 input lines
2 select lines
1 output line

Since:

Number of select lines = log₂(number of inputs)

For 4 inputs:

log₂4 = 2 select lines

S1	S0	Output Y
0	0	I0
0	1	I1
1	0	I2
1	1	I3

Use: Data selection, communication systems, CPU datapaths.

2. Demultiplexer (DEMUX)

A DEMUX does the opposite. It takes one input and sends it to one of multiple outputs.

👉 One → Many

Example: 1:4 DEMUX

              ┌──► Y0
              │
Input ───► DEMUX ──► Y1
              │
              ├──► Y2
              │
              └──► Y3
                 ▲
                S0 S1

There are:

1 input line
2 select lines
4 output lines
S1	S0	Selected Output
0	0	Y0
0	1	Y1
1	0	Y2
1	1	Y3
Key Difference
MUX	DEMUX
Multiplexer	Demultiplexer
Many → One	One → Many
Selects one input	Selects one output
Used for data selection	Used for data distribution
Example: 4:1 MUX	Example: 1:4 DEMUX
