🔌 Topic: UART Communication – Advanced Concepts

Since you've already covered the basics of UART, today let's go one level deeper into how UART works inside an embedded system.

1. What is UART?

UART = Universal Asynchronous Receiver/Transmitter

It provides serial communication between two devices without a clock line.

Example:

Microcontroller  ───── TX ─────>  Computer
Microcontroller  <───── RX ───── Computer
Microcontroller  ───── GND ───── Computer
2. UART Frame Structure

A typical UART frame looks like:

Idle | Start | Data Bits | Parity | Stop |
-----|-------|------------|--------|------|
  1  |   0   |  8 bits    |   -    |  1   |

For an 8N1 configuration:

8 → 8 data bits
N → No parity
1 → 1 stop bit

Example:

Idle   Start       Data          Stop
 1       0      10101010          1
3. What is Baud Rate?

Baud rate represents the number of symbols transmitted per second.

Common UART settings:

Baud Rate	Typical Use
9600	Basic communication
19200	Serial devices
38400	Embedded systems
57600	Faster serial communication
115200	Debugging / MCU communication

For a simple UART signal where one symbol represents one bit:

115200 baud ≈ 115200 bits/second

4. Why Does UART Not Need a Clock?

UART is asynchronous.

Both devices agree beforehand on parameters such as:

Baud Rate
Data Bits
Parity
Stop Bits

For example:

MCU:    115200, 8N1
PC:     115200, 8N1

The receiver uses its own clock to sample the incoming signal.

5. UART Receiver Sampling

The receiver detects the falling edge of the start bit.

Idle
  |
  | Start detected
  ↓
  0 ─────────────────
       ↑
    Sampling

The receiver then samples the data bits at carefully selected points, usually around the middle of each bit period.

This helps tolerate small timing differences between transmitter and receiver.

6. UART Errors

UART can detect several communication problems.

🔹 Framing Error

Occurs when the expected stop bit is not detected.

Possible causes:

Incorrect baud rate
Noise
Incorrect configuration
🔹 Parity Error

Occurs when the received parity does not match the expected parity.

🔹 Overrun Error

Occurs when new data arrives before the previous received data has been read.

Data 1 → RX Buffer
Data 2 → RX Buffer
Data 3 → arrives before Data 1 is processed
              ↓
          Overrun
7. UART vs SPI vs I²C
Feature	UART	SPI	I²C
Clock	No	Yes	Yes
Wires	Usually 2 + GND	4+	2 + GND
Communication	Point-to-point	Master/Slave	Multi-device
Addressing	No	Usually no	Yes
Speed	Moderate	High	Moderate
Duplex	Full duplex	Full duplex	Usually half duplex
💻 Embedded C Example

A simplified UART transmission:

void UART_SendChar(char data)
{
    while (!(UART_STATUS & TX_READY));

    UART_DATA = data;
}

void UART_SendString(char *str)
{
    while (*str)
    {
        UART_SendChar(*str);
        str++;
    }
}

The important concept is:

Check TX Ready
      ↓
Write data to UART register
      ↓
UART hardware sends serial bits
